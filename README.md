# 신규빈 포트폴리오 업로드 안내

## 포함 파일

- `index.html`: 홈페이지 메인 파일
- `assets/`: 이미지와 블렌더 MP4 영상 파일
- `.nojekyll`: GitHub Pages 정적 파일 제공용 설정 파일
- `README.md`: 이 안내 문서

## 기존 GitHub 홈페이지 업데이트

1. 이 ZIP 파일의 압축을 풉니다.
2. https://github.com/cheiresgyu09-ui/Portfolio5 저장소를 엽니다.
3. 기존 index.html이 있는 위치에 압축을 푼 내용물을 올립니다. ZIP 파일 자체나 바깥 폴더를 올리는 것이 아닙니다.
4. `index.html`, `assets` 폴더, `README.md`, `.nojekyll`을 같은 위치에 두고 기존 파일을 교체합니다. `.nojekyll`은 숨김 파일이라 안 보일 수 있습니다.
5. 변경 사항을 커밋한 뒤 GitHub Pages 배포 완료를 기다립니다.
6. https://cheiresgyu09-ui.github.io/Portfolio5/ 에 접속하여 확인합니다.

이미 운영 중인 저장소라면 기존 Pages 설정을 그대로 유지하세요.

## 확인 사항

- 로고 → 블렌더 → 인트로 순서로 사용 도구 위에 배치되어 있습니다.
- PC에서 작품 영역은 본문 너비 전체를 사용합니다.
- 블렌더 3개는 GIF 대신 무음 반복 재생 MP4로 포함되어 있습니다.
- 유튜브 영상은 인터넷 연결이 필요합니다.
- 다운로드한 HTML을 직접 열면 출처 정보가 없어 유튜브 플레이어 구성 오류가 발생할 수 있습니다. 실제 HTTPS 홈페이지에서 확인하세요.
- 실제 홈페이지에서도 재생이 안 되면 영상 아래 'YouTube에서 보기' 링크를 이용하고 오류 번호를 확인하세요.
- 이미지가 안 보이면 assets 폴더를 함께 올렸는지 확인하세요. 파일 이름과 대소문자를 바꾸지 마세요.
- 변경 사항이 안 보이면 배포 완료 후 새로고침하거나 시크릿 창에서 확인하세요.

README는 사용 안내 문서이며, 없어도 홈페이지 자체는 실행됩니다.
